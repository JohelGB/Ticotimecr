# TicoTimeCR — ticotimecr.com

Sitio de TicoTime CR: catálogo por colecciones (191 referencias) y tienda de relojes disponibles con carrito y pedido por WhatsApp.

- `public/` contiene todo lo que se publica.
- `public/disponibles.js` es la lista de relojes disponibles (referencia, nombre, precio, foto y descripción).
- `public/assets/disponibles/` guarda la foto de cada reloj disponible, nombrada con su número de referencia.

Cada cambio que se sube a la rama `main` se publica solo en Cloudflare.
